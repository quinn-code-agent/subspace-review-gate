Accepted journey

01 · TRIGGER

Finished artifact + review request

Not draft chat, bare upload, emoji, “later,” or multiple artifacts.

02 · PREFLIGHT

Prove support or stop

Readable, non-sensitive, one safe URI, fixed hash, and actual Relay capabilities known.

03 · DISCLOSE

Specific offer

Artifact/revision, question, audience, actual expiry, bearer-link risk.

04 · CLEAR YES

Authorized once

Silence, emoji, ambiguity, or changed facts mean no authorization.

05 · PIPELINE

Create → verify → package → publish

Reverify bytes; immutable revision; abort on mismatch.

06 · ROOM

Create + validate

Require matching Briefing, safe URL, authoritative expiresAt.

07 · OUTPUT

URL + expiresAt

No owner/session secrets, refs, IDs, paths, or error bodies.

Repository ownership: one viewer, clear boundaries

subspace-hermes · owner client/plugin

Plugin tools, private owner state, fixed-artifact packaging, and Slack offer/clear-Yes consent. It does not host or duplicate a reviewer UI.

subspace-relay · Relay service

Relay Room and browser UI, sessions, capability URL, storage, access expiry, and later retention sweeping. It is the single hosted viewer implementation.

Future implementation must inventory legacy Hermes Web surfaces and remove stale duplication, retaining an item only for concrete plugin-runtime necessity; no divergent viewer.

Lifecycle vocabulary: distinct controls

Room disable

Stops all Room access. Retained objects are not deleted. Confirm with disabledAt.

Briefing revoke / expiry

Actual expiresAt is authoritative and stops access. The production default is 30 days only when actual Relay capability, preflight, or receipt confirms it.

Session revoke

Ends one supplied session; siblings remain. IDs are not discoverable. Confirm with revokedAt.

Later byte reclamation

Expiry stops access; the sweeper later reclaims bytes. It is not exact-second physical deletion.

Unknown means blocked

Current Hermes has no documented upload cap or accepted-media allowlist and create-room returns no URL or expiresAt. Do not invent limits or infer the 30-day default without actual Relay confirmation.
