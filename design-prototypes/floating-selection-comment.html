Cross-device annotation interaction

Selection should open the next action at the text.

This prototype changes the review surface from a detached sidebar form into an in-context selection workflow: select the words, choose Comment, then write without leaving your reading position.

Desktop: select text, then choose Comment from the floating toolbar. Phone: long-press to use native selection handles, then tap the bottom Comment on selection button.

One annotation model, two device-native interactions

The desktop interface keeps the compact nearby composer. Mobile intentionally uses a bottom sheet: it survives browser toolbars, native selection handles and the keyboard without fighting the operating system.

A submitted comment will later become a portable Subspace Annotation with quote and anchor selectors. This design prototype intentionally does not make a network call.
